### Minor Changes

- 344f183: Initial release of `@macalinao/tsdown-config`, a shared [tsdown](https://tsdown.dev) build configuration for library packages. `defineLibraryConfig()` produces unbundled ESM builds where `dist/` mirrors `src/`, with declarations, source maps, and publint validation enabled by default.
